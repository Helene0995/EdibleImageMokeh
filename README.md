# Edible Image Website

A simple modern landing page for an edible image sales website. It includes a hero section, product showcase, ordering process, testimonials, and contact form.

## Files

- `index.html` – main website page
- `gallery.html` – edible image sample gallery
- `cart.html` – shopping cart page
- `styles.css` – modern responsive styling
- `script.js` – cart and form interaction
- `gallery.html` – product gallery showcasing samples

## Launch locally

Open `index.html` in your browser.
